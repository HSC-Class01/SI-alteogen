결측값과 재무비율을 읽는 방법

금액: 원문/API KRW를 억원으로 변환. 반기 H1은 6개월 누적, Q1은 3개월 누적, Q3은 9개월 누적입니다. 손익의 별도 3개월 수치는 아래 표의 ‘3개월’ 열에 표시합니다. Q2·Q4 독립 보고서는 없으므로 자동 생성하지 않습니다. 현금흐름은 누적, 재무상태는 시점 잔액입니다.

영업이익률=영업이익/매출액, 순이익률=전체 순이익/매출액, 부채비율=부채/자본, 유동비율=유동자산/유동부채, 자기자본비율=자본/자산. ROE·ROA는 전체 순이익/기초·기말 평균 자본·자산이며 기간 기준으로 연율화하지 않습니다. 연결 전체 순이익과 전체 자본을 사용하므로 지배주주 ROE와 다릅니다. 성장률은 같은 보고기간·같은 연결/별도 기준의 전년 매출 대비입니다. 분모가 0 또는 음수인 비율은 표시하지 않습니다.

‘—’는 결측값이며 0이 아닙니다. 2010~2014년은 전체 재무제표 API 미지원으로 원문 검증 CSV만 반영합니다. 연결과 별도는 선택해서 보며 혼합하지 않습니다. 계정 매핑이 중복·모호하거나 통화가 KRW가 아니면 수치를 표시하지 않습니다. 정정보고서 감지 시 해당 기간 API 재조회; 과거 수치가 최신 정정치로 달라질 수 있습니다.
